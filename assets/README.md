# NEXUS Sort generated art pack

This pack contains PNG crops from a generated visual concept atlas. Crops are approximate rectangular regions, so some may include labels or neighboring decoration and are **not yet production-clean transparent sprites**. Use the individual files as visual placeholders/reference; inspect them before integrating into the game.

Main files:
- `menu_bg.png`, `map_bg.png`, `cavern_background.png`
- `gem_*.png`
- `booster_*.png`
- `btn_*.png`
- `effect_*.png`
- `panel_*.png`, `level_complete.png`
- `pipo_*.png`
- `asset_atlas_reference.png` is the full generated atlas.

These files have not been uploaded to GitHub automatically. Extract this ZIP and copy the `nexus_sort_assets` contents into the repository's `assets/` folder. The existing game code still needs to be checked to ensure every path is loaded and rendered correctly.
